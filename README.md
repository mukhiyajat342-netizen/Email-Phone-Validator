# Email&Phone-Validator
A full-stack web application that validates email addresses and phone numbers using HTML, CSS, Python, Flask, and Regex.

## About the Project 
 VerifyNow aims to help users check whether an email address and phone number follow valid formatting rules .

 ## Current Features 
 - Flask backend setup 
 - HTML frontend integration 
 - Basic homepage
